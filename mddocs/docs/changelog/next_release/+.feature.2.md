Use `reWriteBatchedInserts` API for MySQL writes. This improves write performance up to x2 by replacing:

```sql
INSERT INTO mytable VALUES (1);
INSERT INTO mytable VALUES (2);
INSERT INTO mytable VALUES (3);
```

with:
```sql
INSERT INTO mytable VALUES (1,2,3);
```

MySQL JDBC driver keeps both original and replaced `VALUES` in memory, leading to 2x RAM usage. To keep memory usage the same,
`MySQL.WriteOptions(batchsize)` is reduced from `20_000` to `10_000`.
