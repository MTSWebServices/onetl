# 0.17.1 (2026-11-16) { #DBR-onetl-changelog-0-17-1 }

## Bug Fixes { #DBR-onetl-changelog-0-17-1-bug-fixes }

- Fix deadlocks caused by concurrent `Spark.removeSparkListener` calls during garbage collection.
- Reduce `Postgres.WriteOptions(batchsize)` from `20_000` to `10_000`, as `reWriteBatchedInserts=true` requires twice the RAM size compared to `reWriteBatchedInserts=false`.
- Do not drop `sessionInitStatement` value in case ``numPartitions>1`` and missing ``lowerBound`` / ``upperBound`` values.
